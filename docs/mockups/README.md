# Mockups

This folder contains static mockups used to explore Paralleax UX before changing
the production editor.

Mockups are intentionally lightweight HTML/CSS files. They are not source code
for the app, and they should not introduce domain concepts outside the MVP.

## Available Mockups

- [Story Canvas mockups](story-canvas.html): compact canvas, trigger marker
  routing, inspector, and author simulation references.

## Usage

Open the HTML files directly in a browser.

Use these mockups to compare layout, density, visual identity, and interaction
affordances before implementing the corresponding behavior in React.
